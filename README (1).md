# Temperature Converter – Python Mini Project

## Project overview
This beginner-level Python program converts temperature from Celsius to Fahrenheit or Fahrenheit to Celsius.

## Requirements
- Python 3
- Any Python editor (IDLE, VS Code, PyCharm, or an online Python compiler)

## How to run
1. Save `temperature_converter.py`.
2. Open a terminal in the folder containing the file.
3. Run `python temperature_converter.py` (or `python3 temperature_converter.py`).

## Conversion formulas
- Fahrenheit = (Celsius × 9 / 5) + 32
- Celsius = (Fahrenheit − 32) × 5 / 9

## Python concepts
Variables, input(), print(), float(), if-elif-else, arithmetic operators.

## Sample test
Select 1 and enter 25.
Expected result: 77.0 F.

## Note
This is a basic educational program. It converts between Celsius and Fahrenheit only.
